# Forma ReTrace prototype brand assets

The active application logo is [Autodesk Forma ReTrace](../public/brand/autodesk-forma-retrace.png), the revised PNG created from the owner's original logo at their request. Only the lower product name was requested to change to `Forma ReTrace`, retaining the same visual font size. The application uses the selected revised image unchanged; CSS scales it proportionally without cropping or recoloring.

The revised file is 2242 × 701 pixels and has SHA-256 `3efbfa5bd848f2c1524891f8962f5d8c10825fe7bf08d330542845340f88a2d4`. It is an image-editing output, not a byte-identical version of the original artwork. The accessible name is `AUTODESK Forma ReTrace`.

## Reference provenance

The original `Autodesk Forma ReCap.png` was copied byte-for-byte to `public/brand/autodesk-forma-recap.png`. Its SHA-256 remains `206f6b435eda9cc3292ecf1e60d89449aadcb47c0f647a2f20751139336c9c7c`. The earlier [replacement preview](images/logo-replacement-preview.jpg) records that historical version.

The earlier prototype SVG compositions combined the three references below. Those original source files remain preserved unchanged in `public/brand/references/`:

- `Autodesk Forma logo.svg`: Autodesk symbol, `AUTODESK` and `Forma` outline geometry, isolated from the supplied square background using nested SVG viewports.
- `Autodesk logo.png`: reference for the white Autodesk symbol on black; the matching vector symbol from the supplied Forma artwork was used for sharp output.
- `Autodesk ReCap logo.jpeg`: reference for the actual Autodesk ReCap product's typography and stacked hierarchy. The historical SVG compositions outlined that former word in Arial Regular.

Historical brand and source filenames retain their original spelling. This repository does not grant rights to Autodesk marks; see [the provenance notice](../NOTICE.md).
