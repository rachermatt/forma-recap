# Content and provenance

Forma ReTrace is a local prototype. This repository does not represent an Autodesk product release or establish Autodesk endorsement.

The active `public/brand/autodesk-forma-retrace.png` is the revised logo requested by the project owner. Its earlier source `public/brand/autodesk-forma-recap.png` remains preserved unchanged. Historical alternate logo files and Autodesk product names are reference branding. The repository does not grant rights to Autodesk names, logos or other third-party marks.

The corridor illustrations, reference plan and labeled synthetic recapture in `server/media/` are prototype fixtures. Their display derivatives preserve separate source and display hashes. The versioned demo bundle contains only the synthetic project and its local demonstration decisions, not customer site photographs or live APS project data.

`examples/photograph-import-demonstration.html`, its JSON manifest and `docs/images/photograph-review-preview.jpg` retain an earlier mechanism test using a photographic composite from the owner-supplied concept deck. Its capture date/location and real-project applicability are unverified. No separate redistribution license for that supplied reference image is recorded here; inclusion does not imply a general reuse license. Saved packet contents are preserved unchanged.

Source review documents identify the supplied concept deck, speaker notes and workflow references by filename. Raw supplied PDFs, PowerPoint files and the handoff ZIP are not included; the repository contains the prior extracted handoff documentation and the prototype's generated reports.

No open-source license has been selected for the application. Third-party npm packages retain their own licenses, available in their installed package distributions. Credentials, local user evidence databases, uploaded private photographs, build outputs and dependencies are excluded from Git.
